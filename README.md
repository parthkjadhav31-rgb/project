# 🔐 Cyber Crime Investigation Simulator

A beginner-friendly Python project that simulates a cyber crime investigation using digital evidence and suspect analysis.

## 📌 Project Description

This project is a simple cybersecurity simulation where a confidential file has been accessed suspiciously. The user can select a suspect, and the program analyzes simulated digital evidence to calculate a suspicion score and determine the risk level.

## ⚙️ Features

- Suspect selection
- Simulated digital evidence
- Login activity analysis
- Suspicion score calculation
- Risk level classification
- Investigation report

## 🛠️ Technologies Used

- Python
- Dictionaries
- Loops
- Conditional Statements
- User Input

## ▶️ How to Run

1. Open `cyber_crime.py`
2. Run the Python program
3. Select a suspect from 1 to 3
4. The program analyzes the simulated evidence
5. View the final investigation report

## 🎯 Purpose

The purpose of this project is to demonstrate basic Python programming concepts through a cybersecurity-themed simulation.

## ⚠️ Disclaimer

This is an educational simulation only. It does not perform real hacking, cyber attacks, or real-world investigations.
